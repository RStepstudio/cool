What is password entropy?

Entropy is the number of random bits in a password. It is the only honest way to compare a passphrase against a complicated-looking string, because it maps directly to how many guesses an attacker needs.

Quick answer: Entropy is measured in bits. A password from a 94-character alphabet has about 6.55 bits per character, so 16 random characters is about 105 bits. PassMeter shows the exact bit count for any password you type.

How do I calculate password entropy?

Entropy equals the log base 2 of the keyspace, and the keyspace equals the character-set size raised to the password length. For a 94-character set at 12 characters: log2(94^12) is about 79 bits. For a lowercase-only 12-character password: log2(26^12) is about 57 bits.

Does entropy account for human-made patterns?

No, and this is the flaw in naive calculators. A tool that sees "Passw0rd2024" in a 94-character alphabet reports 94^12 bits, while the real keyspace is tiny because crackers assume capitalisation swaps, appended years and dictionary words. PassMeter's crack-time model uses the actual character classes present, which is closer to reality, but treat any number as a floor rather than a guarantee.

What is a good entropy score for a password manager master key?

Aim for 80 bits or more, ideally 100+. A 20-word diceware list or a 20-character random string both exceed that comfortably. A 16-character random string from a 94-character set lands near 105 bits.

How does entropy relate to crack time?

Directly. Crack time is roughly keyspace divided by two, divided by guesses per second. At 10 billion guesses per second, a 60-bit password falls in about a day, while an 80-bit password takes longer than the universe has existed to have existed.
