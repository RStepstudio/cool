How do I create a strong password?

Length beats complexity. The single most effective change you can make is going from 8 to 16 characters, then protecting that password with a manager.

Quick answer: Use a passphrase of four or more unrelated words (roughly 20+ characters), or a random 16+ character string generated by a password manager. Add symbols and numbers only if a service forces them. Enable two-factor authentication everywhere the option exists.

Is length or complexity more important for a password?

Length. Every extra character multiplies the search space. Going from 8 to 12 characters is a 15,000x increase in guesses needed; adding one symbol to an 8-character password is roughly a 30x increase. Length is cheaper to remember and easier to type, so it is nearly always the better trade.

Why is a passphrase better than a complex password?

Complex passwords like P@ssw0rd!2024 look strong but follow predictable patterns: a word, a symbol swap, a year. Attackers use those rules. violin-lantern-sausage-42 has far more entropy, is easier to remember, and is rarely in a wordlist.

How much entropy does a good password need?

  • Below 40 bits - cracked instantly by any modern GPU rig.
  • 40-60 bits - hours to days against a modern rig; weak for important accounts.
  • 60-80 bits - years to centuries with current hardware. Good.
  • 80 bits and above - effectively uncrackable for the foreseeable future.

Should I reuse a strong password on multiple sites?

No. A single reused password turns one site breach into access to every account you own. Uniqueness matters more than raw complexity, which is exactly what a password manager is for.

How often should I change my password?

Modern guidance from NIST SP 800-63B says change passwords only when you have evidence of compromise, and never force routine rotation. Change immediately if it appears in a breach database, if you reused it, or if you shared it.
