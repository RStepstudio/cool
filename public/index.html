How does the checker work?

PassMeter measures the true keyspace of your password: the size of the character classes you actually use, raised to the power of the length. That keyspace is halved (an attacker gets halfway on average) and then divided by the cracking speed of a 1990 workstation (about 1,000 guesses per second) and of a modern GPU cluster (about 10 billion guesses per second). The result is a realistic crack-time estimate for both eras, plus the exact number of bits of entropy.

What do the two times actually mean?

The 1990 figure shows how safe a password looked to the average person in 1990. The modern figure shows what the same password is worth to an attacker today. The gap between them is why passwords that felt strong three decades ago are now worthless.

Why is the breach check anonymous?

The check uses k-anonymity: your browser hashes the password with SHA-1, sends only the first five characters of that hash, and matches the returned suffixes locally. The server never receives your password or your full hash, so it cannot identify you or store your credential.

Frequently asked questions

How do I check if my password is strong?
Type it into the field above. The meter, the bit count and both crack times update on every keystroke, and the breach check runs a moment after you stop typing.
Is it safe to check my password online?
It is safe here. Strength is scored entirely by JavaScript in your browser, so the password never reaches a server. The only outbound request is the anonymised hash-prefix lookup used for breach counts.
How long would my password take to crack in 1990?
On a 1990 workstation guessing roughly 1,000 times per second, nearly every modern password was uncrackable in practice. Today's figure uses a far more realistic 10 billion guesses per second, which is what a rented GPU cluster can achieve.
What is a good bit count for a password?
At least 60 bits for everyday accounts, and 80 bits or more for email, banking and password manager master keys. A 16-character random password from a 94-character alphabet is about 105 bits.
How do I make a strong password I can remember?
Use a passphrase of four or five unrelated words, or let a password manager generate a long random password for you. Avoid predictable edits like P@ssw0rd, which cracking tools try within the first few hundred guesses.
