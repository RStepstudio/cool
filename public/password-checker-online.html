Is it safe to check my password online?

Short answer: it depends entirely on the tool. The safest checkers score your password in the browser and never send it. The least safe require you to sign in or email it.

Quick answer: Check passwords only in tools that run entirely in your browser, like PassMeter. If a page asks for your email address, an account, or an uploaded file, close it. Your password should never need to travel to be scored.

What happens to my password when I paste it into a checker?

It depends on the design. Browser-only tools evaluate strength with JavaScript and the text never leaves your device. Server-side tools POST the password to a backend for scoring, which means it exists in a server log, a cache, or an error report. Some tools do not even have a privacy policy describing retention.

Which signs show a checker is not storing your password?

  • It works with JavaScript disabled? No - but it works fully offline after the page loads.
  • No login, no email field, no "send me a report" option.
  • Browser developer tools show the password is never sent in a request payload.
  • The breach check uses a hash prefix, so only part of a hash is transmitted.

How does PassMeter check for breaches without revealing my password?

It uses k-anonymity through the Have I Been Pwned range API. The browser computes a SHA-1 hash of your password, sends only the first five characters of that hash, and receives back every suffix starting with those five characters. The server never learns your hash, and your password never leaves the page.

What should I do if I already pasted a password into an untrusted site?

  1. Change that password immediately, starting with email and banking.
  2. Enable two-factor authentication on the affected account.
  3. Check for other accounts where you reused the same password.
  4. Watch for unexpected login emails or password reset requests.

Can a password checker be used safely on a work device?

Yes if the tool is browser-only and your organisation permits it. Company policy usually matters more than the tool: many employers require audits for any third-party page handling credentials.
